# Zero-Knowledge Proofs for Blockchain Developers Course
link : https://aliibrahimmohammed.github.io/Zero-Knowledge-Proofs-for-Blockchain-Developers-Course/

This comprehensive course covers zero-knowledge proofs from mathematical foundations to advanced Noir programming techniques. The course is designed for blockchain developers looking to understand and implement ZKP systems.

## Course Structure

| Module | Title | Description |
|--------|-------|-------------|
| [Module 1](modules/module-1-mathematical-foundations.md) | Mathematical Foundations | Groups, Fields, Elliptic Curves |
| [Module 2](modules/module-2-introduction-zkp.md) | Introduction to ZKPs | zk-SNARKs, zk-STARKs, Bulletproofs |
| [Module 3](modules/module-3-practical-zkp-concepts.md) | Practical ZKP Concepts | Provers, Verifiers, Trusted Setup |
| [Module 4](modules/module-4-introduction-noir.md) | Introduction to Noir | Programming Language Overview |
| [Module 5](modules/module-5-basic-proof-circuits.md) | Basic Proof Circuits | Writing Circuits in Noir |
| [Module 6](modules/module-6-advanced-techniques.md) | Advanced Noir Techniques | Complex Circuit Design |

## Prerequisites

- Basic understanding of blockchain concepts
- Familiarity with programming concepts
- Understanding of cryptography fundamentals (helpful but not required)

## Getting Started

To begin the course, start with [Module 1: Mathematical Foundations](modules/module-1-mathematical-foundations.md) and work through each module in sequence.
